## Component meaning

- Protocol records are technical rows, not dashboard cards.
- Protocol items are labeled machine components.
- The Re-entry Rail is the primary chronology instrument.
- Amber marks the current edition, current day, or next active return only.
- Publication fixes an edition rather than celebrating completion.
- Version history is rendered as an immutable technical ledger.
- Client preview uses the same Skin Pass artifact and rail vocabulary as the client product.

## Production deviations

The implementation intentionally uses accessible selects and buttons for chronology instead of drag-only editing. Dragging was optional in the product contract and would have duplicated functionality without improving the first production slice.

The Figma preview shows representative authored states. Production renders the actual client evaluation engine from unsaved draft data, including unknown-item and symptom-language boundaries.

At narrow widths, the desktop two-column authoring instrument becomes a single-column sequence. The Re-entry Rail remains fully editable and the publication action becomes non-sticky so content and focus order remain predictable.

The static Figma publication review demonstrates a Day 10 to Day 9 change. Production computes the difference from the previous immutable snapshot.
